# Lambda Language Specification
<sub>SPEC VERSION: 0.1-alpha</sub>

Welcome to the canonical specification for the Lambda programming language.
This directory documents the syntax, semantics, type system, standard library and module system for Lambda.

## Table of Contents

1. [Syntax](syntax.md) – Keywords, operators, grammar rules, and identifiers.
2. [Types](types.md) – Built-in types, type coercion, and rules.
3. [Functions](functions.md) – Standard library functions and intrinsics.
4. [Modules](modules.md) – Module system, visibility, and scoping rules.
5. [Classes](classes.md) – Class syntax, methods, and OOP rules.
6. [Examples](examples/) – Example `.lm` scripts demonstrating language features.
7. [Roadmap](roadmap.md) – Planned additions and future revisions.
